# MiniAssist 1.4.1 — Fabric 1.21.4

Клиентский мод для Minecraft на Fabric: современная тёмная ClickGUI в фиолетово-синем стиле, настраиваемые бинды, HUD, Aim Assist, TriggerBot и FreeCam.

## Функции

### Aim Assist — F6
- Самостоятельно и плавно доводит обзор до выбранной цели: ЛКМ удерживать не нужно (это можно включить отдельной настройкой).
- Настройки: дистанция, FOV, плавность, максимальный поворот за тик, упреждение движения цели.
- Удержание цели, фильтр невидимых и выбор типов целей.
- По умолчанию выбирает игроков; враждебных и мирных существ можно включить в настройках.
- Не наводится через стены и отключается, пока активна FreeCam.

### TriggerBot — F7
- Проверяет цель под прицелом один раз за игровой тик.
- Учитывает ванильный кулдаун атаки. При стандартных 100% не спамит ударами, даже если игрок стоит на месте.
- Дополнительная задержка настраивается именно в игровых тиках.
- Таймер сбрасывается при респавне и смене мира.
- Режим «Только критические» ждёт настоящего ванильного окна крита; подмена пакетов и принудительные криты не используются.
- Есть фильтры по дистанции, невидимости, типам целей и использованию предмета.

### FreeCam — F8
- Отделяет камеру от персонажа и удерживает игрока на исходной позиции.
- WASD, прыжок, приседание и ускорение используют назначенные в Minecraft клавиши, а не жёстко прописанные кнопки.
- Скорость и множитель Sprint настраиваются отдельно в ClickGUI.
- При выключении камера, позиция, направление, скорость и состояние падения корректно возвращаются игроку.
- При смене мира и отключении от сервера модуль безопасно выключается; камера и временно захваченные клавиши возвращаются.

### HUD — G показывает/скрывает
- Отдельные тёмные полупрозрачные панели с фиолетово-голубыми акцентами в духе Nursultan 1.16.5.
- Watermark MiniAssist с FPS и сетевым ping.
- Список активных модулей с назначенными клавишами.
- Координаты, направление и горизонтальная скорость.
- Иконки брони с полосками прочности.
- Эффекты зелий с уровнем и оставшимся временем.
- Target HUD с именем, здоровьем, дистанцией и ping игрока, если он доступен.
- Keystrokes с WASD, прыжком и подсветкой ЛКМ/ПКМ.
- Каждый блок можно отдельно включить или выключить в Render → HUD.
- На небольшом разрешении HUD упрощает watermark, ограничивает длину подписей и скрывает панели, которые начали бы перекрываться.

## ClickGUI и бинды

- **Right Shift** — открыть или закрыть меню.
- **ЛКМ по переключателю модуля** — включить или выключить его.
- **Ползунки** — менять значения настроек перетаскиванием мыши.
- **BIND** — нажать, затем нажать новую клавишу.
- **Delete / Backspace** — очистить бинд; **Esc** — отменить назначение.
- При назначении уже используемой модулем клавиши старый конфликтующий бинд очищается.
- **G** зарезервирована для показа/скрытия HUD; **Right Shift** — для меню.
- Настройки и бинды сохраняются в `config/miniassist.properties`.
- Колесо мыши прокручивает список модулей.

## Сборка через GitHub Actions

1. Распакуй ZIP-архив.
2. Загрузи **всё содержимое архива прямо в корень репозитория** (рядом должны лежать `build.gradle`, `gradle.properties`, `settings.gradle`, `src/` и `.github/`). Не загружай только ZIP и не создавай дополнительную вложенную папку. Важно: вместе с остальными файлами загрузи и скрытую папку `.github/workflows/`.
3. Сделай Commit в любую ветку. Workflow запускается при каждом Push; ручной запуск доступен через **Actions → MiniAssist Build → Run workflow**.
4. После успешной сборки открой завершённый запуск и скачай **Artifacts → MiniAssist-1.4.1**.
5. Распакуй артефакт и помести `zenith-client-1.4.1.jar` в папку Minecraft `mods` рядом с Fabric API.

Workflow самостоятельно устанавливает Temurin Java 21 и Gradle 8.12 через GitHub Actions; локальный Gradle Wrapper не требуется. Исправлена отрисовка иконок брони: в Yarn 1.21.4+build.8 используется `DrawContext.drawStackOverlay(...)` (а не `drawItemInSlot(...)`). При падении Gradle GitHub Actions также загружает лог сборки как `MiniAssist-build-log`. Проект настроен на Fabric Loom 1.10.5, Minecraft 1.21.4, Yarn `1.21.4+build.8`, Fabric Loader 0.16.9 и Fabric API 0.112.2+1.21.4.

## Совместимость и примечания

**Целевая версия этого проекта — Minecraft 1.21.4.** Nursultan 1.16.5 используется только как визуальный ориентир для HUD-панелей: тёмные полупрозрачные карточки, компактные подписи и цветовые акценты. Это не порт на Minecraft 1.16.5 и не копирование кода или ресурсов Nursultan. На мультиплеерных серверах использование боевых модулей может быть запрещено правилами сервера — соблюдай их.

## Что исправлено и проверяется в версии 1.4.1

- Сбой отдельного модуля логируется, модуль автоматически отключается, а остальные функции продолжают тикать.
- Ошибка конфигурации не должна завершать запуск клиента; невалидные значения пропускаются, а запись конфига остаётся атомарной.
- HUD ограничивает длину текста, подстраивает watermark и меняет расположение/скрывает панели на узком окне, чтобы не перекрывать друг друга.
- При отключении от сервера FreeCam принудительно выключается, сохраняет конфигурацию и возвращает камеру/клавиши.
- Бинды модулей остаются уникальными: назначение занятой клавиши очищает предыдущий конфликт.
